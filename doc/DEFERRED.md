# 별건으로 넘긴 것

심의가 찾았으나 **그 트랜치의 소관이 아니어서** 넘긴 것들. 여기 없으면 심의 기록에만 남고,
그 기록은 세션과 함께 사라진다 — `RELEASE.md` §7 이 「Fable 미이수」를 표로 남기는 것과 같은 이유다.

⚠ **여기 있는 것은 「나중에 고친다」가 아니라 「알고 있다」다.** 우선순위는 오너가 정한다.
고칠 때는 그 줄을 지우고 커밋 메시지가 근거를 승계한다.

---

## 검사기 구멍

- **`check-shipped-claims.mjs` 관할이 md 3개뿐이다.** 사이드바 라벨·툴팁도 고객이 읽는 문면인데
  금지 주장 검사 밖이다(위 거짓 둘이 그래서 살아남았다).
- **`check-sidebar-labels.mjs` 의 `STATES` 가 `SidebarState` 의 타입 없는 손짜기 복제본이다.**
  `folderPath` 로 한 번 드리프트했고 그때 검사기가 예외로 **통째로 죽었다**. 판정을 총체적으로
  고쳐 지금은 안 죽지만, 다음 필드는 **조용히** 빠진다(잘못된 칸을 검사하게 된다).
  정석: 상태 목록을 core 에서 타입 있는 값으로 내보내 검사기가 소비한다.
- **`RENDERS_AS_LINK` 오라클이 두 벌이고 정의가 다르다** — `notice.test.ts`(닫는 괄호 미검사·
  스킴 무제한) vs `tenantScope.test.ts`(스킴 3개 열거). 후자는 전자가 「목록은 늘어난다」며
  **명시적으로 배격한 형상**이다.
- `check-notice.mjs` 가 알림 호출의 `arguments[0]` 만 본다 — `MessageOptions.detail` 과 QuickPick
  항목 라벨이 관할 밖(그 파일이 스스로 적어 둔 구멍).
- 트리 `description` 은 **대입**이라 보간 검사가 못 본다(`folderShown`). 지금은 사람이 주석으로
  못박아 뒀다.

## 문면 — 지시대상 없는 「이 폴더」

- **`relinkConfirm`**(`extension.ts` 의 재연결 동의 모달)에 폴더 경로가 없다. 그 모달에서 사람이
  방금 고른 것은 **사이트**이지 폴더가 아니고, 폴더는 며칠 전 열어 둔 주변값이다. 0.13.0 이 세운
  잣대(「모달이 서는 순간 지시대상이 사람 눈에 있(었)는가」)에 이 모달은 걸린다.
  `pickedFolderLinkConfirm`(방금 손으로 고른 폴더)과는 다르다 — 그쪽은 기각이 옳다.
- `help.md` 「묶음과 단추는 그대로입니다」 — 조건부 **버튼** 둘(「미리보기 중지」·「이 폴더의
  사이트로 돌아가기」)이 있어 엄밀히는 안 맞는다. **같은 절 2판째라 재개서를 권고하지 않는다**
  (3판 규칙). 다음에 그 절을 만질 일이 생기면 같이 본다.

## 주입·소독

- **상태바 `${input.tenant}` 가 맨값이다** → `$(아이콘)` 주입. `StatusBarItem.text` 는 `$(…)` 해석을
  **계약으로 보증**하고, `zalkera.tenant` 는 `scope` 미선언이라 폴더의 `settings.json` 이 덮는다
  (형제 `apiBase`·`npm` 은 바로 이 이유로 `scope: machine` 이다).
  ⚠ **`plainNotice` 로는 안 닫힌다** — 그 소독기는 `$(` 를 안 지운다. 별도 판단이 필요하다.

## 성능 (전부 소규모·기존)

- `refreshSidebar` 1회에 `currentFolderBinding()` 이 **2번** 돈다(`showIdleStatus()` 안 1번 +
  상태 객체 1번) — 같은 두 파일을 두 번 lstat+read+parse.
- `activate()` **동기** 구간의 `showIdleStatus()` → 동기 `lstat`+`readFileSync`.
- `readProvenance` 가 64KB 만 읽을 것을 위해 항목 상한만큼 임시 자리에 실체화할 수 있다
  (적대 입력 한정). 죄려면 해제기에 항목별 상한 노브가 필요해 「저수준 판독기 하나」와 상충한다.

## 한계 — 고칠 수 없다고 판정된 것

- **구판이 남긴 밀린 링크.** 사이트 선택이 열린 폴더의 링크를 덮던 시절의 재고. 정상 입양도
  링크만 남기므로 「링크 단독 = 의심」 규칙을 세울 수 없다 — **기계적 판별 불가.**
  ⚠ 다만 **표식과 링크가 둘 다 있고 서로 다른 칸은 판별된다.** 지금은 표식이 조용히 이기고 끝난다.
  그 부분집합을 화면에 말하게 하는 것은 설계를 받아야 한다(다음 트랜치 후보).
- **재진입 가드는 창을 못 넘는다** — VS Code 는 창마다 확장 호스트가 따로다(`reentrancy.ts` 기명).
- **소속 없이 태어나는 폴더를 전수 봉쇄할 수 없다** — git clone·기계 복사·대행사 폴더.
  그래서 방어가 **발행 초크포인트**에 있다.

## 종결 — 다시 올리지 말 것

- **BUSY 반송 낭비**(해제가 도는 중 대화상자를 답하고 옆 폴더까지 만든 뒤에야 물러난다).
  기능 축·성능 축이 각각 제안, 구현이 두 번 기각, 설계가 기각 — **네 번**. 고치는 것은 드문
  경쟁 상황의 흔적(빈 폴더 하나·미리보기 재시작 한 번)이고 잔재는 `nextAvailableName` 이
  `-2` 로 비켜 손해가 없다. 대가로 「지금 푸는 중인가」를 묻는 자리가 둘이 된다.
