# zalkera-devtools

잘커라(zalkera) 사이트를 **자기 컴퓨터에서** 고치고, 보고, 올리기 위한 도구 모음.

잘커라에서 소스는 **외양만** 담당한다 — 화면·배치·마크업. 상품·재고·주문·예약은 서버에 있고 소스는
그것을 가리키기만 한다. 그래서 껍데기를 통째로 바꿔도 장사는 안 끊긴다.

이 레포는 그 껍데기를 **로컬에서 다루는 레일**이다. 편집 자체는 하지 않는다 — 편집은 당신이 쓰는
편집기와 AI(예: Claude Code, Codex)가 한다.

## 무엇이 들어 있나

| 패키지 | 무엇 | 상태 |
|---|---|---|
| [`packages/core`](packages/core) | 러너 — 자격증명 획득 · 환경 조립 · 개발 서버 기동 · 패킹 · 발행 | **구현됨** · 내부 패키지(npm 미발행) |
| [`packages/cli`](packages/cli) | `@zalkera/cli` — 터미널에서 쓰는 길(명령은 `zalkera`) | **npm 발행됨** |
| [`packages/vscode`](packages/vscode) | VS Code 확장 — 터미널 없이 쓰는 길 | **마켓플레이스 배포됨** |

셋은 **같은 코어**를 쓴다. 어느 길로 오든 동작이 같다.

## 하려는 일

```
소스를 구한다  →  로컬에서 연다  →  AI 에게 말하거나 직접 고친다
                                    ↓
                              미리보기로 확인한다   ← 이 레포가 여는 것
                                    ↓
                                  발행한다
```

**우리 AI 를 쓰든 당신이 쓰는 LLM 을 쓰든 대등하다.** 잘커라 콘솔에서 말로 고치는 길과, 여기서 로컬로
고치는 길은 어느 쪽도 다른 쪽의 통행료가 아니다.

## 상태

VS Code 확장은 **마켓플레이스에 올라 있다** — [zalkera.zalkera-devtools](https://marketplace.visualstudio.com/items?itemName=zalkera.zalkera-devtools).
설치해서 바로 쓸 수 있다.

| | 무엇 | 상태 |
|---|---|---|
| 설계 | 형상·계약·비목표 확정 | ✅ |
| 레포 뼈대 | 모노레포 3패키지 · MIT | ✅ |
| 서버 측 | 확장용 로그인 클라이언트 · 미리보기 전용 키 · 버전 핸드셰이크 | ✅ |
| **코어** | 자격증명 · 의존성 · env 조립 · 개발 서버 · 패킹 · 발행 | ✅ |
| **확장** | 로그인 → 소스 받기(예제·내 사이트) → 미리보기 → 발행 → 롤백 | ✅ 배포됨 |
| 소스 MCP 연동 | 에이전트가 발행·롤백·상태를 도구로 부른다 | ✅ |
| CLI | `npx @zalkera/cli` — 받기·올리기·발행·되돌리기·버리기 · 상태 | ✅ npm 발행 · 미리보기·로컬 MCP 는 아직 |

`packages/core` 는 확장이 쓰는 **내부 패키지**라 npm 에 올리지 않는다. 확장 VSIX 안에 번들로 실린다.

## 확장이 하는 일은 넷뿐이다

1. **런타임 배달** — Node 를 따로 깔지 않아도 되게 한다. VS Code 가 이미 싣고 있는 것을 쓴다.
2. **자격증명 배달** — 미리보기용 키를 받아 `.env.local` 의 정해진 칸만 채운다(당신이 넣어 둔 나머지 값은 보존한다).
3. **등록 대행** — 당신이 쓰는 에이전트의 MCP 설정에 잘커라 서버를 적어 준다.
4. **프로세스 관리** — 개발 서버 시작·중지·로그.

로직은 `core` 와 서버에 둔다. 확장이 두꺼워지면 CLI·데스크톱에서 재사용할 수 없다.

## 안 만드는 것

의도적으로 비운 자리다. 이유가 있어서 비어 있다.

| 안 만드는 것 | 왜 |
|---|---|
| 확장 안의 채팅 UI | 에이전트가 이미 한다. 만들면 우리 토큰이 들어가고 "당신의 LLM 으로 고친다"가 거짓이 된다 |
| 확장·서버의 자체 LLM 호출 | 같은 이유. 자연어 해석은 전부 당신 쪽에 남는다 |
| 웹뷰 미리보기 | iframe 은 쿠키·CSP 가 실제 탭과 달라 "로컬에선 됐는데 배포하니 다르다"를 만든다. 실제 브라우저로 연다 |
| 코드 편집 보조 | 에이전트 영역이다 |
| 벤더 전용 에이전트 스킬 | 지침의 정본은 `llms.txt` 하나다. 벤더별 사본은 반드시 어긋난다 |

## 요구사항

- **VS Code**(또는 Cursor·Windsurf 같은 포크) — 확장으로 쓸 때
- **Node.js 20+** — CLI 로 쓸 때만. 확장 경로는 Node 설치가 필요 없다
- 잘커라 계정과 사이트 하나

## 보안

- 로그인 토큰은 VS Code **SecretStorage** 에만 둔다. 파일에 쓰지 않는다.
- 개발 서버가 쓰는 키는 `.env.local` 에 들어가고, 확장이 `.gitignore` 를 함께 손본다.
- 이 레포는 공개다 — **주소·엔드포인트는 설정으로 받고 시크릿은 커밋하지 않는다.**
- 미리보기는 **당신의 실제 상용 데이터**를 읽는다. 미리보기 키로는 쓰기가 안 되고, 그 차단은 서버가 집행한다.

## 관련

- [`@zalkera/client`](https://www.npmjs.com/package/@zalkera/client) — 스토어프론트가 서버 데이터를 읽는 공식 라이브러리
- `llms.txt` — 껍데기를 짓는 법의 정본 명세(위 패키지에 동봉). **이 도구 없이도 명세만으로 지을 수 있어야 한다**
