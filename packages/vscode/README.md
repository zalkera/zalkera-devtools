# 잘커라 (zalkera)

**내 사이트를 내 컴퓨터에서 열고, 고치고, 바로 확인하고, 올립니다.**

터미널을 쓰지 않아도 됩니다. 명령 몇 개면 끝납니다.

---

## 처음 쓰실 때

`Ctrl+Shift+P`(Mac 은 `Cmd+Shift+P`)를 누르고 **`잘커라`** 라고 치면 명령이 보입니다.

1. **잘커라: 로그인** — 브라우저가 열립니다. 쓰시던 잘커라 계정으로 로그인하세요.
2. **잘커라: 예제 zip 다운로드** — 예제를 zip 파일로 받습니다.
3. **잘커라: zip 으로 시작** — 그 zip 과 **빈 폴더**를 고르면 예제 사이트가 들어옵니다.
4. **잘커라: 미리보기 시작** — 잠시 뒤 브라우저에 내 사이트가 뜹니다.

> 이미 운영 중인 사이트가 있으시면 ②③ 대신 **잘커라: 소스 다운로드** 하나면 됩니다 —
> 빈 폴더를 고르면 지금 배포 중인 소스가 바로 들어옵니다.

처음 한 번만 시간이 좀 걸립니다(필요한 파일을 받아 둡니다). 다음부터는 몇 초입니다.

---

## 고치는 방법

**이 확장은 코드를 대신 고치지 않습니다.** 고치는 건 두 가지 중 편하신 쪽입니다.

- 직접 편집기에서 고치기
- 쓰시던 AI(Claude Code · Codex 등)에게 말로 시키기

**어느 쪽이든 저장하면 미리보기에 바로 반영됩니다.**

> 저희 AI 를 쓰셔도 되고 안 쓰셔도 됩니다. 이 확장에 채팅을 넣지 않은 이유가 그것입니다 — 이미 결제하고 계신 AI 를 그대로 쓰시는 게 맞습니다.

---

설명서: <https://zalkera.github.io/zalkera-devtools/> (확장 안에서는 「도움」 → **도움말**)

## 명령 한눈에

| 명령                               | 하는 일                                                                     |
| ---------------------------------- | --------------------------------------------------------------------------- |
| **로그인** / **로그아웃**          | 잘커라 계정 연결                                                            |
| **예제 zip 다운로드**                    | 예제 사이트를 받아 새로 시작합니다                                          |
| **소스 다운로드**               | 운영 중인 내 사이트를 컴퓨터로 가져옵니다                                   |
| **소스 zip 다운로드**              | 같은 소스를 풀지 않고 zip 파일 하나로 받습니다                              |
| **zip 으로 시작**                  | 받으신 zip 과 **빈 폴더**를 고르면 그 소스가 들어옵니다                     |
| **zip 으로 교체**                  | 이미 열어 두신 폴더의 소스를 새 zip 으로 갈아 끼웁니다                      |
| **zip 으로 내보내기**              | 지금 폴더를 zip 하나로 묶습니다 (올리지는 않습니다)                         |
| **서버 판으로 교체**               | 지금 폴더를 지우고 **서버에 켜져 있는 판**으로 바꿉니다                     |
| **사이트에 연결**                      | 이미 가진 폴더를 내 사이트로 잇습니다                                       |
| **사이트 선택**                    | 다룰 사이트를 고릅니다 — 사이드바에서는 맡으신 사이트가 여럿이면 **사이트 전환** 으로 보입니다 |
| **작업 폴더 변경**                 | 이 창을 다른 폴더로 옮깁니다 (**소속은 안 바꿉니다**)                       |
| **이 폴더의 사이트로 돌아가기**    | 폴더와 사이트가 어긋났을 때 폴더 쪽 사이트로 맞춥니다                       |
| **미리보기 시작 / 미리보기 중지 / 미리보기 다시 시작** | 고친 결과를 브라우저에서 봅니다                       |
| **새 버전 배포**                 | 고친 소스를 올려 **사이트를 그것으로 바꿉니다** (올리는 중에 그만두실 수 있습니다) |
| **버전 전환**                      | 사이트를 다른 판으로 바꿉니다(되돌리기도 여기서)                            |
| **버전 이력**                      | 지난 버전들을 봅니다 (아무것도 바뀌지 않습니다)                             |
| **배포 전 검사**                   | 올리기 전에 살펴봅니다 (막지는 않습니다)                                    |
| **에이전트 연결(MCP)**             | 쓰시는 AI 가 사이트를 다룰 수 있게 설정을 적어 줍니다                       |
| **진단**                           | 안 될 때 무엇이 문제인지 알려 줍니다                                        |
| **초기화**                         | 로그인·사이트 설정·미리보기 자격증명을 지웁니다 (**받은 소스는 안 지웁니다**) |
| **도움말**                         | 쓰는 방법을 처음부터 봅니다                                                 |

## 편집 중에 알려 드리는 것

배포한 뒤에야 드러나는 문제를 **미리** 짚어 드립니다.

- 브라우저에서 잘커라 서버를 직접 부르는 코드 — 배포하면 막힙니다
- `NEXT_PUBLIC_` 에 넣은 비밀 값 — 방문자에게 그대로 보입니다
- 소스에 적어 둔 접속 키
- `@zalkera/client` 에 없는 이름을 쓴 곳

되돌리기 어려운 파일(`.env`·`node_modules` 등)을 **고치시면** 한 번 알려 드립니다. **막지는 않습니다.**

---

## 알아 두실 점

**미리보기는 실제 운영 데이터를 읽습니다.** 내 상품과 콘텐츠가 그대로 보이는 건 그래서입니다.

미리보기 중에는 **주문·결제 같은 쓰기가 서버에서 막힙니다.** 실수로 진짜 주문이 생기지 않습니다.

**미리보기 자격증명은 한 번에 하나입니다.** 다른 컴퓨터에서 미리보기를 켜면 이쪽이 해제됩니다 — 해제되면 알려 드립니다.

**로그인 정보는 VS Code 의 보안 저장소에만 둡니다.** 프로젝트 폴더에 저장하지 않으니, 소스를 남에게 주셔도 계정이 따라가지 않습니다.

## 안 될 때

**잘커라: 진단** 을 먼저 실행해 보세요. 대부분 여기서 원인이 나옵니다.

그래도 안 되면 **보기 → 출력** 을 열고 오른쪽 목록에서 **`잘커라`** 를 고르세요. 무슨 일이 있었는지 적혀 있습니다. 그 내용을 보내 주시면 도와 드리겠습니다.

## 필요한 것

- **VS Code 1.90 이상** (Cursor·Windsurf 에서도 됩니다)
- **잘커라 계정** — 사이트를 관리할 수 있는 권한이 필요합니다

**Node.js 는 따로 설치하지 않으셔도 됩니다.** 없으면 없는 대로 뜹니다.

이미 깔려 있으면 미리보기가 **더 빠른 엔진**으로 알아서 바뀝니다. 화면과 동작은 같고,
첫 화면이 뜨는 시간만 다릅니다.
고르실 것은 없습니다 — 있으면 쓰고, 없으면 안 씁니다.

## 설치와 갱신

마켓플레이스에서 설치하시면 새 판이 나올 때 자동으로 갱신됩니다.

갱신이 안 온다 싶으면 이 한 줄로 최신 판에 맞출 수 있습니다. 지우지 않으니 안전합니다.

```bash
code --install-extension zalkera.zalkera-devtools --force
```

Cursor·Windsurf 같은 포크에는 아직 올리지 못했습니다. 그쪽에서는 `.vsix` 파일로 까셔야 하고,
자동 갱신도 오지 않습니다.
