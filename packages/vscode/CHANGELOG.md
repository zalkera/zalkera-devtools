# 변경 기록

## 0.1.x — 초기 판(Preview)

잘커라 사이트를 자기 컴퓨터에서 열고, 프리뷰로 확인하고, 올립니다.

- **런타임 배달** — Node·npm 을 따로 설치하지 않아도 됩니다. VS Code 가 품은 Node 로 동봉 npm 을 돌립니다.
  설정 `zalkera.npm` 으로 **이 컴퓨터의 npm** 을 쓰게 바꾸실 수 있고, 고른 것을 못 쓰면 말하고 멈춥니다.
  npm 은 이름이 아니라 **경로**로 부르고, 의존성 설치 때 **설치 스크립트를 돌리지 않습니다**.
- **업데이트 안내** — 서버가 더 나은 판을 알려 주면 알림이 뜨고, 「업데이트」가 확장 화면으로 데려갑니다.
  같은 소식은 하루에 한 번만 뜹니다.
- **사이트 열기** — 콘솔에서 받은 소스를 열고 의존성을 준비합니다.
- **프리뷰** — 실제 데이터로 화면을 보되 쓰기는 막습니다.
- **올리기** — 고친 소스를 압축해 올립니다.

> Preview 판입니다. 형상이 바뀔 수 있습니다.
